# 江味齋 POS（單機平板收銀）

Android 平板用的離線收銀系統。資料只存在平板本機（IndexedDB），列印透過 RawBT 送到 58mm 藍牙出單機。與點餐 App 完全獨立。

## 安裝
1. 把這個資料夾放到 HTTPS 網址（例如 GitHub Pages 的新 repo `jiangway-pos`）。
2. 平板用 Chrome 開啟網址 → 選單 →「加到主畫面／安裝應用程式」。
3. 平板安裝 RawBT（`ru.a402d.rawbtprinter`）並配對出單機，先用 RawBT 自己的測試列印確認可印。
4. 開 POS →「設定」→ 設定店主 PIN → 填店家資料 →「測試列印」。

## 功能
點餐、品項客製與備註、單品／整單折扣、掛單取單、現金／刷卡／EFT／餐券（可分開付款、現金找零）、
廚房單＋收據、訂單來源、訂單查詢與重印、作廢（PIN＋原因）、日結報表與現金對帳、
菜單管理、售完設定、CSV 匯出、備份匯出／匯入。

## 注意
- 資料只在這台平板。請定期到「設定 → 匯出備份」。
- 折扣一律四捨五入到整 Rand。
- 作廢的訂單會從營業額與現金應有金額扣除（視為已退款）。
